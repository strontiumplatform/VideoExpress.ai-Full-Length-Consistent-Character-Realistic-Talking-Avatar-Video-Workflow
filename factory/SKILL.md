# VideoExpress Workflow Factory

Follow `factory/WORKFLOW_FACTORY.md` in this repository phase by phase. It is the
complete operating manual: Phase 0 loads `factory/FOUNDATIONS.md` (verified selectors
and doctrines — ground truth, never re-derive) and the root `SYSTEM_PROMPT.md` (gold
standard skeleton); Phases 1–7 run interview → style study → design matrix → prompt
authoring → live validation → page generation from `factory/templates/` → publish.

Non-negotiables carried from the foundation: Reliability Rules R1–R8 and Traps 1–5
verbatim in every new prompt; ≤100-character actor scripts; public gallery unticked
before every generation; backend model never named; copy-paste as the primary install
path; nothing unverified shipped as fact.
